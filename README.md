# My Stack-chan

M5Stack CoreS3を使用した、個人用AIアシスタントの開発プロジェクトです。

## 開発目標

- サーボモーターを使用しないCoreS3単体への対応
- Wi-Fiを利用した音声会話
- Raspberry Piを使ったAIバックエンド
- マイクのノイズ抑制・音声入力の安定化
- CodexやClaude Codeとの連携
- Googleカレンダー・IoT機器との連携
- 外出先からの利用
